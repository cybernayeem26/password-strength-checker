# Password Strength Checker

## Overview

A Python-based cybersecurity tool that evaluates password strength using industry-standard password complexity requirements.

The project includes:

* Command Line Interface (CLI) version
* Graphical User Interface (GUI) version using Tkinter

## Features

* Password length validation
* Uppercase letter detection
* Lowercase letter detection
* Number detection
* Special character detection
* Password scoring system
* Strength categorization (Weak, Medium, Strong, Very Strong)
* Security recommendations
* Common password detection
* Repeated character detection
* Progress bar and color-coded strength indicator
* Show/Hide password functionality

## Technologies Used

* Python
* Tkinter
* Regular Expressions (Regex)
